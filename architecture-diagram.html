MedTrace AI — Radiology Workflow

AI-assisted radiology report generation with MedSAM2 segmentation + MedGemma/Qwen VL inference

Frontend Stack

  • • React 19 + TypeScript + Vite
  • • TailwindCSS dark theme (#060b14)
  • • Single-file SPA (App.tsx)
  • • Three-panel layout: Study / Viewer / Decision
  • • Interactive ROI drawing on DICOM viewport

Backend Stack

  • • FastAPI + Uvicorn + Pydantic v2
  • • DICOM processing (pydicom + windowing)
  • • Pluggable model adapters (HTTP/Local/Mock)
  • • CORS for localhost dev (5173-5177)
  • • Static file serving for study data

AI Models

  • • MedSAM2: ROI-based medical image segmentation
  • • MedGemma: Radiology report generation (4 modes)
  • • Qwen VL via Nebius: Cloud-based vision-language
  • • Mock mode: Deterministic fallback for dev/testing
